# Face Detection and Recognition System

## Description

This project is a real-time face detection and recognition system
using Python, OpenCV and the face_recognition library.

## Technologies Used

- Python
- OpenCV
- NumPy
- face_recognition
- Jupyter Notebook

## Features

- Real-time face detection
- Face recognition using webcam
- Face encoding and comparison
- Displays the recognized person's name
- Displays "unknown" for unrecognized faces
